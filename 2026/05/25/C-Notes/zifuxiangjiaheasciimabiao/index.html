字符相加(char类型)与 ASCII 码

LeonardoFox2026-05-25

1. 关键结论：整型提升（Integer Promotion）

规则：short 和 char 类型的数据在参与运算（如加、减法等）的时候，系统会先自动将它们提升为 int 类型，然后再进行运算。

  • 背后的逻辑：字符在计算机底层其实就是一串二进制数字（即 ASCII 码）。
  • 因此，char 类型的本质就是一个小整型，它完全可以像数字一样参与加减运算。

2. 案例拆解

案例 A：字符转化为数字参与运算

  • 解析：字符 'a' 对应的 ASCII 码值是 97。当执行类似 'a' + 1 的运算时，'a' 会先变成 int 型的 97，再加上 1 得到 98。

案例 B：输出格式决定显示结果

  • 解析：内存里存的都是 97。你用 %d 去看它，它就是数字 97；你用 %c 去看它，它就会去查 ASCII 码表，把对应的图形 'a' 打印出来。

3. 技巧：ASCII 码表免背指南（VS 实操）

虽然常见的 ASCII 码有规律可循（例如：数字连续、大写字母连续、小写字母连续），但完全不需要死记硬背！在 Visual Studio 中，直接利用 printf 配合 %d 就可以随时“白嫖”任何字符的编码：

核心记忆卡片

  • 字符 'a' 的 ASCII 码 97
  • 字符 'A' 的 ASCII 码 65
  • 字符 '0' 的 ASCII 码 48
  • 记住这个公式：'a' - 'A' = 32（大小写字母的 ASCII 码值正好相差 32）。
