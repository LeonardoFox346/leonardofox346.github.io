📖 详细图文教程

获取原版系统镜像

首先需要从MSDN下载原版的Windows系统镜像。建议选择Windows 10/11 ConsumerEditions或BusinessEditions，功能完整且适合封装。

版本选择建议 推荐选择Windows 10 专业版或Windows 11 专业版。专业版版本功能全面，兼容性最好。

下载完成后，使用Bandizip或7-Zip将ISO文件解压到一个剩余空间大于50Gb的硬盘。解压后你会看到以下目录结构：

目录结构
# 典型的Windows ISO解压结构 sources/

├── boot.wim # 启动镜像（PE环境）

├── install.wim # 系统安装镜像（这是我们要修改的）

└── ...

bootmgr

setup.exe

...

install.wim（Windows Imaging Format）就是我们需要精简和封装的核心文件。

使用NTLite精简镜像

NTLite是镜像精简的核心工具，可以在不解压WIM的情况下直接编辑系统镜像。

2.1 加载镜像

打开NTLite，点击"添加" → "镜像文件(WIM, ESD, SWM)"，选择刚才解压的sources/install.wim。

重要提示 如果镜像中包含多个版本（如家庭版、专业版、企业版），NTLite会列出所有版本。建议选择专业版(Pro)或企业版(Enterprise)进行编辑，这两个版本功能最完整。
2.2 精简组件

加载完成后，在左侧菜单可以看到各类可精简的项目：

  • 组件移除：删除不需要的Windows组件，如OneDrive、Cortana、Xbox应用等
  • 功能设置：启用或禁用.NET Framework、Hyper-V、WSL等功能
  • 驱动整合：提前注入网卡、显卡等驱动，避免安装后无网卡驱动
  • 更新整合：将累积更新补丁整合进镜像，安装后就是最新版
  • 注册表：添加优化注册表，如关闭自动更新、优化服务等
  • 无人值守：配置自动应答文件，实现全自动安装
精简建议 初次封装建议保守精简，只移除明显的冗余组件（如Xbox、Cortana、OneDrive），保留运行库和系统组件。过度精简可能导致系统不稳定。
2.3 保存镜像

配置完成后，点击上方的"应用"按钮，选择"保存为WIM/ESD"。最开始建议选择WIM格式，速度更快。

虚拟机安装与配置

在虚拟机中安装精简后的系统，进行进一步的个性化配置和软件预装。

3.1 创建虚拟机

在VMware中新建虚拟机，注意以下配置：

  • 固件类型：选择BIOS（兼容性更好）或UEFI（根据目标机器选择）
  • 磁盘：2块,一块系统盘建议30GB以上，另一块再磁盘管理创建 把之后要用的Easysysprep,和你要用的软件塞进去,建议大于20Gb
  • 内存：分配4GB以上保证流畅运行
  • 网络：删除网卡,不要联网
3.2 系统安装与优化

使用精简后的ISO安装系统，进入桌面后可以进行以下配置：

PowerShell
# 系统优化命令（以管理员运行CMD或PowerShell） # 1. 关闭自动更新（可选） reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU" /v NoAutoUpdate /t REG_DWORD /d 1 /f # 2. 禁用休眠（节省空间） powercfg /hibernate off # 3. 关闭系统还原（封装前建议关闭） reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\SystemRestore" /v DisableSR /t REG_DWORD /d 1 /f # 4. 清理临时文件 cleanmgr /sagerun:1
3.3 预装软件

安装你需要的常用软件，建议包括：

  • 浏览器：Chrome、Edge或Firefox
  • 解压工具：7-Zip或Bandizip
  • 运行库：VC++运行库合集、.NET Framework
  • 输入法：搜狗、QQ拼音或微软拼音
  • 其他必备：Notepad++、PotPlayer等
软件安装注意事项 预装软件时不要登录账号（如浏览器账号、Office账号），保持软件为"首次启动"状态。登录信息会在封装后被清除，且可能导致部署到新机器时出现冲突。
系统封装（Sysprep）[强烈建议看视频进行操作!!!]

这是最关键的一步，使用Sysprep工具将系统"通用化"，清除硬件相关信息和用户数据，使其可以在不同配置的机器上部署。

4.1 准备封装环境

在封装前，务必进行以下清理：

  • 清理浏览器历史记录和缓存
  • 删除临时文件（运行%temp%并清空）
  • 清空回收站
  • 卸载不需要的驱动（特别是显卡驱动，建议封装前卸载）
  • 运行磁盘清理工具
4.2 使用Easy Sysprep

相比系统自带的Sysprep，Easy Sysprep提供了更友好的界面和更多选项：

  1. 这里建议看视频操作!!!
  2. 以管理员身份运行Easy Sysprep
  3. 选择"封装"模式
  4. 勾选"通用"（Generalize）选项，这是关键！
  5. 选择关机模式为"关机"（不是重启）
  6. 点击"确定"开始封装
什么是"通用化"？ Generalize会清除系统中的硬件相关信息（如SID、硬件驱动缓存、事件日志等），让系统可以在不同硬件配置的机器上启动并重新检测硬件。如果不勾选此项，镜像只能在与当前虚拟机相同配置的机器上使用。
4.3 封装后处理

封装完成后虚拟机会自动关机。务必启动到PE再次运行Sysprep！否则封装会被破坏。

使用使用VMWERE BIOS菜单启动到微PE ISO，继续操作。

最后封装

打开EasySysprep 完成最后的设置 (此处`建议看视频操作!!!)

测试与部署

在正式安装前，务必进行充分测试。

6.1 虚拟机测试

新建一台虚拟机，使用生成的ISO安装系统，检查：

  • 安装过程是否顺利（特别是无人值守配置是否生效）
  • 系统能否正常启动和运行
  • 预装软件是否正常
6.2 实机测试

在实体机上测试，特别是：

  • 不同品牌的主板（Intel/AMD芯片组）
  • NVMe固态硬盘兼容性
  • USB3.0/3.1驱动是否正常（安装过程中鼠标键盘是否可用）
  • 显卡驱动是否能自动安装或正常手动安装
重要提醒 首次测试建议在不影响工作的机器上进行。确保镜像稳定后再用于主力机或他人机器。

❓ 常见问题

封装后的镜像体积还是很大，如何进一步精简？

可以尝试：1) 使用ESD格式替代WIM，压缩率更高；2) 在NTLite中移除更多组件（如Windows Defender、Windows Update）；3) 使用CompactOS功能压缩系统文件；4) 删除预装软件的多语言包。

部署时出现"Windows无法完成安装"错误？

通常是虚拟机与目标机硬件差异过大。也可能是无人值守文件配置错误。建议检查NTLITE精简，确保没有删除重要程序。

如何集成显卡驱动到镜像中？

在NTLite的"驱动"选项卡中，点击"添加"选择驱动文件夹。建议从显卡官网下载驱动解压后添加，而不是使用.exe安装包。注意：NVIDIA驱动需要添加Display.Driver文件夹中的.inf文件。

封装后的系统激活状态会保留吗？

不会。Sysprep会清除激活信息。建议在封装前不激活系统，或在部署后使用服务器、数字权利激活等方式重新激活。

🎉 写在最后 封装Windows镜像是一个需要耐心的过程，第一次可能会遇到各种问题。建议多准备几个虚拟机快照，随时回滚重试。当你成功部署第一个属于自己的系统时，那种成就感是无与伦比的！如果在过程中遇到问题，可以点击网页顶部的网页设置-帮助中心获取帮助
